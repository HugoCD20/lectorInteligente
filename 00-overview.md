

# LectorInteligente

## Descripción

``Este proyecto surge de la necesidad de leer libros digitales en diferentes idiomas,facilitando su traducción, sin perder el texto original``

## Objetivo

````
Crear una aplicación web responsiva que permita ingresar archivos de texto (pdf,docs,txt), y traducirlos al idioma seleccionado.
````


## Público objetivo

Este proyecto está dirigido para lectores que necesiten  traducir textos de manera más accesible.

## Tecnologías

- Django
- flutter
- PostgreSQL
- Libretranslate
